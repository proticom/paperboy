# @proticom/paperboy-ai

Shared AI provider catalog and image-description helpers for Paperboy hosts (CLI, desktop app).

- Provider registry: OpenRouter, OpenAI, Anthropic, xAI, Ollama, local OpenAI-compatible endpoints
- `describeImageWithAi` — host-agnostic; callers resolve API keys and pass `AiConfig`

See `paperboy-cli` for keychain/env integration.
