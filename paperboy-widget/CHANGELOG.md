# Changelog

All notable changes to this package will be documented in this file.

The format is based on [Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.2] - 2026-05-26

### Added
- jsdom integration tests against the built `dist/paperboy-widget.min.js` bundle (`e96536a`).

## [0.2.1] - 2026-05-25

### Changed
- Masthead toggle sizing; compact mode opt-in; configurable collapse (`8ef3480`).
- Pill slider anchored to toggle cells with flex layout (`0748270`).

## [0.2.0] - 2026-05-14

### Added
- `data-toggle-mount-target` to embed the toggle in a host container (`f3d5d8f`).
- Paper-aesthetic redesign, inline render mode, and theming knobs (`fad60bf`).

### Changed
- Aligned all workspace package versions to 0.2.0 (`3d0bf2b`).

## [0.1.0] - 2026-04-11

### Added
- Initial embeddable markdown/web toggle widget.
